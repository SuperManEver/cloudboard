# CloudBoard — AWS Learning Project Roadmap

> **Goal:** Build a small, production-oriented project and task management application while learning AWS infrastructure, authentication, databases, serverless APIs, testing, and deployment.

## Technology stack

- **Frontend:** Next.js 15 (App Router), React, TypeScript, Tailwind CSS
- **Runtime:** Node.js 24 (`.nvmrc`)
- **Infrastructure as code:** AWS Amplify Gen 2 (TypeScript / AWS CDK / CloudFormation)
- **Authentication:** Amazon Cognito User Pools with Google federation (OAuth 2.0 / OIDC)
- **Data API:** AWS AppSync (GraphQL, generated by Amplify Data)
- **Database:** Amazon DynamoDB
- **Custom backend (later):** AWS Lambda + API Gateway HTTP API
- **Hosting and CI/CD:** AWS Amplify Hosting connected to GitHub `main`
- **Testing and monitoring (later):** TypeScript tests, Playwright, CloudWatch

## Development principles

1. **Learn one AWS service at a time.** Introduce services to implement a concrete feature.
2. **Develop in an isolated Amplify sandbox.** Avoid experimenting directly against the hosted `main` backend.
3. **Treat authentication and authorization separately.** A valid Cognito token does not imply access to another user's records.
4. **Design DynamoDB access patterns before indexes.** Prefer key-based queries to broad scans.
5. **Inspect what Amplify generates.** Review CloudFormation, AppSync resolvers, IAM permissions, and DynamoDB tables.
6. **Keep cloud costs visible.** Avoid unnecessary always-on resources and monitor AWS Billing.
